# 📖 Инструкция для репетитора — Бот «Учёт занятий»

Привет! Это простая инструкция, как пользоваться ботом. Никаких технических знаний не нужно — только Telegram.

---

## 🎯 Что умеет бот

- Считает, сколько занятий осталось у каждого ученика
- Автоматически списывает занятие, когда вы кидаете ссылку на Google Meet
- Пополняет баланс по команде `+4` (или любое другое число)
- Показывает сводку по всем ученикам
- Предупреждает, когда у ученика заканчиваются занятия

---

## 🚀 Первый запуск

### 1. Напишите боту `/start` в личные сообщения

Бот ответит, что вы назначены **репетитором (админом)**. Это важный шаг — только админ может добавлять учеников и смотреть статистику.

> ⚠️ Это нужно сделать один раз. Если вы уже написали `/start` и бот ответил — всё готово.

### 2. Выберите язык (если нужен английский)

По умолчанию бот говорит по-русски. Чтобы переключиться на английский:
```
/lang en
```

Чтобы вернуть русский:
```
/lang ru
```

---

## 👨‍🎓 Как добавить ученика

### Способ 1. Через личные сообщения боту (если знаете ID)

Отправьте боту команду:
```
/addstudent [chat_id ученика] [ID группы] [Имя]
```

**Пример:**
```
/addstudent 123456789 -987654321 Иван
```

- `123456789` — личный chat_id ученика
- `-987654321` — ID группы (начинается с минуса)
- `Иван` — имя ученика

> 💡 Узнать ID можно командой `/myid`. Попросите ученика написать боту `/myid` в личку — он получит свой номер.

### Способ 2. Автоматически (проще)

1. Создайте группу в Telegram и добавьте туда бота и ученика
2. Попросите ученика написать **любое сообщение** в группу
3. Бот автоматически зарегистрирует его

---

## 💰 Как пополнить баланс занятий

Есть два способа:

**В личных сообщениях ученика:**
- Ученик пишет боту: `+4`
- Бот отвечает: *«Пополнение на 4 занятия. Текущий баланс: 4»*

**В группе:**
- Ученик (или вы) пишет в группу: `+4`
- Бот тоже засчитает пополнение

> Можно писать `+4`, `+ 4`, `пакет +4` — бот поймёт.

---

## 🎥 Как проходит занятие (списание)

1. Вы кидаете в группу ссылку на Google Meet, например:
   ```
   https://meet.google.com/abc-defg-hij
   ```
2. Бот **автоматически** списывает 1 занятие
3. Ученик видит сообщение: *«Урок начался и засчитан. Осталось занятий: 3»*
4. Вы получаете уведомление в личку с текущим балансом ученика

> Если у ученика **0 занятий**, бот не даст начать урок и напишет вам об этом.

> Если осталось **1 занятие**, бот предупредит ученика (и вас), чтобы не забыли пополнить.

---

## 📊 Как посмотреть статистику

Напишите боту в личку:
```
/stats
```

Бот покажет список всех учеников:
```
📊 Сводка по ученикам:

• Иван: 4 занятия (последнее: 27.04.2026 15:30)
• Мария: 1 занятие (последнее: 25.04.2026 10:00)
```

---

## 🆔 Как узнать ID группы или свой ID

- Напишите боту `/myid` **в личку** — получите свой личный номер
- Напишите `/myid` **в группе** — получите ID группы

---

## ❌ Как удалить ученика

Отправьте боту в личку:
```
/deletestudent [chat_id ученика]
```

---

## ⚠️ Если бот «задумался» (не отвечает сразу)

Бот работает на бесплатном сервере. Если никто не писал ему **больше 15 минут**, он "засыпает". **Первое сообщение после сна он обработает через 30-60 секунд** — это нормально.

Просто подождите немного, или отправьте сообщение ещё раз.

---

## 🆘 Что делать, если что-то пошло не так

| Проблема | Решение |
|----------|---------|
| Бот не отвечает вообще | Подождите 1 минуту, напишите снова. Если не помогло — напишите человеку, который настраивал бота |
| Бот не списал занятие | Убедитесь, что ссылка именно на `meet.google.com`. Проверьте, зарегистрирован ли ученик (`/stats`) |
| Ученик не может пополнить баланс | Проверьте, зарегистрирован ли ученик. Если нет — пусть напишет что-нибудь в группу |
| Бот пишет "Вы не зарегистрированы" | Ученик ещё не добавлен. Добавьте вручную (`/addstudent`) или пусть напишет в группу |
| Я случайно удалил бота из группы | Просто добавьте обратно. Данные никуда не пропадут |

## 📱 Коротко: основные команды

| Команда | Где писать | Что делает |
|---------|-----------|------------|
| `/start` | Личка боту | Стать админом (один раз) |
| `/lang ru` или `/lang en` | Личка боту | Сменить язык бота |
| `/addstudent ID группа Имя` | Личка боту | Добавить ученика вручную |
| `/stats` | Личка боту | Сводка по всем ученикам |
| `/myid` | Личка или группа | Узнать свой ID или ID группы |
| `/deletestudent ID` | Личка боту | Удалить ученика |
| `+4` | Личка или группа | Пополнить баланс на 4 занятия |
| `meet.google.com/...` | Группа | Автоматически списать занятие |
